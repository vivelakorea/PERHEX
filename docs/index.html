01Why

Crystal-plasticity RVEs are usually voxel meshes: periodic boundary conditions are trivial, but every grain boundary becomes a staircase. Conforming meshes fix the geometry but are tetrahedral, and node-matched periodicity is usually sacrificed. PERHEX gives all four properties at once — measured on the same 20-grain microstructure (voxel N=40 vs PERHEX):

45.2°
mean voxel GB facet normal error vs the true Laguerre plane (p90: 70°). PERHEX: 0° by construction.
1.497×
voxel GB surface area inflation — every surface-integrated GB quantity inherits it. PERHEX: exact.
4.4° / 15.9°
median / p90 GB-plane rotation during 10 % tension — trackable only on a conforming mesh (voxel normals are wrong at t=0).

Any model input measured on the mesh geometry inherits these errors — GB tractions for decohesion, slip-transfer criteria evaluated on facets, and distance-to-boundary fields (see the GB-distance study).

03Method

One hexahedron per cell vertex

Every vertex of a generic Laguerre cell touches exactly three edges and three faces. Each cell therefore splits into one hex per vertex, with corners

(v, m(e₁), c(f₁₂), m(e₂), m(e₃), c(f₁₃), C, c(f₂₃))

— the vertex, three edge midpoints, three face centroids, and the cell centroid. A grain-boundary face is covered by quads whose four corners all lie in the face plane: planarity is exact by construction, not an approximation.

Periodicity by re-tessellation

The periodic seed set plus its 27 images is re-tessellated on the unit cube, so opposite boundary traces are exact translates of each other; a cut-position optimizer keeps the cube planes away from tessellation vertices. Opposite-face node sets then match to <10⁻¹² and standard 3-dummy *EQUATION PBCs apply directly.

Grading that survives periodicity

Each coarse hex is refined n³ with one global geometric schedule tᵢ = (rⁱ−1)/(rⁿ−1). All three local zero-planes of a corner hex lie on cell faces, so the same schedule refines toward every grain boundary — and because it is shared by all hexes, conformity and periodicity are preserved bitwise.

Verification

  • element volumes tile the domain to 10⁻⁹
  • all 2×2×2 Gauss Jacobians positive in every element
  • 100 % of opposite-face/edge/corner nodes matched, in-plane offsets <10⁻¹²
  • 10 % uniaxial-tension CPFEM: periodic displacement jumps constant across every face pair to ~10⁻⁹ relative

04Usage

# 1. periodic tessellations (Neper >= 4), screened for minimum feature size
bash pick_tess.sh                 # candidates cand_*.tess
python eval_tess.py               # rank by min edge; best -> rve.tess

# 2. cube cut + midpoint hexes + graded refinement (n=4, ratio=1.5)
python -c "from build_cube_rve import make_cut_tess; make_cut_tess()"
python gen_midpoint_hex.py 4 1.5

# 3. self-contained Abaqus deck (mesh + PBC + per-grain material)
python gen_mp_deck_oxford.py      # -> oxford_mp/rve_oxford.inp

# 4. run with OXFORD-UMAT
abaqus job=rve_oxford user=OXFORD-UMAT.f cpus=8 double=both

Requirements: Neper ≥ 4.10 with gmsh 4.8.x, Python 3 + numpy, Abaqus. The deck is fully self-contained (mesh, PBC equations, per-grain orientations and properties in one .inp).

05GB storage term for OXFORD-UMAT

oxford-patch/ adds the Haouala-type grain-boundary dislocation storage term to the Kocks–Mecking model of OXFORD-UMAT (6 small patches + one new file; K_s = 0 is bit-identical to upstream):

ρ̇̇ₙₙₔ = ( max( k₁√ρₖ,  Kₙ/dₚ ) / b − k₂ρₙₙₔ ) |γ̇|

where dₚ is the slip-direction distance to the nearest grain boundary, per element and slip system. Three dₚ modes:

modedₚmechanism
dbconvect=0frozen t=0 table literature practice (Haouala 2018: “computed and stored at the beginning… assumed not to change”)
dbconvect=1chord convection dₚ(t) = dₚ₀·|F·s₀|, purely local
dbconvect=2live ray-trace GB facet quads tracked by their actual nodes (*Node File → .fil → URDFIL each increment); Möller–Trumbore against precomputed candidate lists; the t=0 trace reproduces the exact Laguerre distances to machine precision

The dₚ tables come from exact closed-form ray tracing in the periodic Laguerre diagram (gen_db_table.py), with staircase-geometry variants for corruption studies. Details in oxford-patch/README.

Live mode needs mp_mode=threads and rate-limits the per-increment dₚ change (±5 %): the raw facet-tracked distance steps discontinuously when the hit facet changes, and feeding that step straight into the explicit hardening update collapses the time increment (measured).

Results (10 % tension, aluminium KM, Kₙ=5, <d>=9.2 μm)

All four runs completed with the explicit state update; every PBC jump constant to ~10⁻⁹. Flow stress is the volume-weighted ⟨σ₁₁⟩ — on a boundary-graded mesh the naive element average over-weights the hardened GB layers (by 30 % here; an easy trap).

R3 midpoint, staircase dₚ, frozen67.6 MPa+1.7 %
R4 voxel, staircase dₚ, frozen62.1 MPa−6.7 %

What the decomposition says, honestly:

  • The frozen-dₚ assumption is safe for the macroscopic curve (R2 vs R1: −0.1 %) — even though the live distances drift hard locally: by 10 % strain, 17 % of (element × slip system) rays changed by more than 10 %, with extremes at 0.17× and 24× the initial value. Macro-safe, locally large — anything evaluated per-boundary (slip transfer, decohesion) sees the drift the average hides.
  • The dₚ input corruption self-averages (R3 vs R1: +1.7 %): a median-30 % scatter in a distance that enters through max(k₁√ρ, Kₙ/dₚ) largely cancels in the mean response.
  • The mesh itself is the biggest term (R4 vs R1: −6.7 %): with identical physics and near-identical inputs, the staircase discretization alone softens the predicted response by several times more than either dₚ effect.

07Curved boundaries (phase-field input)

The midpoint construction is combinatorial — it needs trivalent junction topology, not planar faces. Feeding it a phase-field grain-growth microstructure (MOOSE, periodic 40³, Fan–Chen multi-order-parameter) gives conforming all-hex periodic meshes with curved grain boundaries: order-parameter-based junction extraction (a generalized Euler gate V−E+F−annuli = χ verified against an independent voxel-surface characteristic), one hex per (grain, quadruple point), n³ graded refinement, and sub-voxel projection onto the OP iso-surfaces (<1 voxel moves). The single failure mode is topological: a grain that percolates through the periodic box (genus > 0 boundary) cannot be filled by a single-apex midpoint fan — it needs a multi-apex decomposition (standard handle-cutting, implementation deferred).
